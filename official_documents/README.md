```
C:\ProgramData\Blackmagic Design\DaVinci Resolve\Support\Developer\Scripting
C:\ProgramData\Blackmagic Design\DaVinci Resolve\Support\Developer\Fusion
```

`<version>_Scripting/`と`<version>_Fusion/`へ版ごとに保存し、旧版は保持する。
Fusionの資料本文の更新日はResolveの版と一致するとは限らないため、両方を検証記録へ残す。
